# English Class Manager (TKCA)
Ứng dụng Quản lý điểm danh, Lịch dạy và Báo cáo lương cho Giáo viên Tiếng Anh. 
Xây dựng trên nền tảng **Flutter** + **Supabase**.

## 📌 Các tính năng chính (Hoàn tất)
1. **Quản lý học sinh & Chi nhánh**: Thêm học sinh, gán chi nhánh, chọn môn học và thiết lập lịch học định kỳ trong tuần.
2. **Sinh lịch học tự động**: Dựa vào lịch đăng ký của học sinh, hệ thống sẽ tự động tính toán số buổi trong tháng và sinh ca học (Sessions).
3. **Lịch chấm màu mượt mà**: Lịch tháng và thanh cuộn ngày (Ruler Picker) trực quan với các điểm chấm màu tương ứng môn học/học sinh.
4. **Điểm danh Vuốt để xóa**: Giao diện Swipe-to-delete vuốt từ phải sang trái (RTL) có tính năng hoàn tác (Undo) trong 5 giây.
5. **Thông báo nhắc nhở**: Lập lịch Push Notification (Local) nhắc nhở xác nhận điểm danh khi ca học kết thúc.
6. **Xuất Excel tự động**: Xuất file `.xlsx` Báo cáo lương tháng phân loại theo từng chi nhánh, tự động chèn thông tin tài khoản ngân hàng và chia sẻ qua Share Sheet.

## 🚀 Hướng dẫn cài đặt

### 1. Cấu hình Supabase (Database)
Bạn cần chạy script SQL để tạo bảng và cấu hình RLS. Mở file tại:
`docs/SUPABASE_SETUP.sql`
Copy toàn bộ nội dung và chạy vào phần **SQL Editor** trong project Supabase của bạn.

### 2. Cấu hình App kết nối Supabase
Mở file `lib/core/constants/supabase_config.dart`.
Thay thế hai biến `supabaseUrl` và `supabaseAnonKey` bằng thông tin Project của bạn:
```dart
class SupabaseConfig {
  static const String supabaseUrl = 'https://[PROJECT_ID].supabase.co';
  static const String supabaseAnonKey = '[YOUR_ANON_KEY]';
}
```

### 3. Cài đặt Flutter & Build
Đảm bảo bạn đã cài đặt Flutter SDK và cấu hình Android SDK.
```bash
# 1. Tải các thư viện
flutter pub get

# 2. Build APK Android
flutter build apk --release
```
